# CU / GS IP 매핑 분석

> **분석 기준**: 기존 `ip_keywords.parquet` (256개 IP) 대비 CU·GS 신규 IP 목록 비교  
> **판정 기준**:  
> - ✅ **기존 사용** — `ip_keywords.parquet`에 동일·유사 항목 존재, 재추출 불필요  
> - 🟡 **확인 후 사용** — 표기 차이 또는 관련 IP 존재, 매핑 전 확인 필요  
> - ❌ **신규 추출** — 기존 없음, 키워드 새로 추출 필요
