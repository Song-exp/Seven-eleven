## 지표 요약 (상세 정의·공식 → `docs/keyword_classification_criteria.md` §1·§2)

표 읽기에 필요한 핵심만 recap — **전체 공식·근거는 위 기준서가 정본**:
- **purity** = `Score_succ/(Score_succ+Score_fail)` — k로 흘러든 어텐션 중 성공제품 비중(어텐션 가중, 모델 관점). **기준선은 0.5가 아니라 base 0.238**(>0.238 성공특이 / <0.238 실패특이). 빈도 무관 비율값이라 키워드 간 동일 잣대 비교 가능.
- **WoE** = `ln((supp_s/n_succ)/(supp_f/n_fail))` — purity의 **순수 카운트 버전**(통계 관점, 희소성 편향 X). 기준선=0(>0 성공·<0 실패). killer는 `purity≥0.50` **AND** `WoE>0`를 둘 다 요구(어텐션 아티팩트 방어).
- **Δprob**(개입·재추론) = 캐리어 고정+k 토글 시 성공확률 변화 = killer/mine/매개 확정의 인과 축.
- **주의**: 빈도 1~2 소표본은 supp_f(또는 supp_s)=0이라 WoE가 ±13처럼 발산 → 절댓값 크다고 강한 신호 아님(빈도 floor·Wilson 하한이 거름).

## 표기 규약

각 칸 = `키워드(빈도 / purity 마크)`, purity 내림차순.
- 첫 숫자 = **빈도**(직접 has_kw 제품 수), 둘째 = **purity**.
- **마크** — killer/mine은 Δprob 개입검증 판정, 매개는 등급(grade):

| 마크 | killer | mine | 매개 |
|---|---|---|---|
| ✅ | 확실(Δ>+0.01) | 진짜 악재(Δ<−0.01) | — |
| ❓ | 불명확(노이즈, ±0.01) | 불명확 | — |
| 🔶 | 조건부(IP 있을 때만 +) | — | — |
| ⚠ | — | 통계만(의심, Δ≥0) | — |
| 🟢 | — | — | T1(무조건+ , delta_pos=1.0) |
| 🔵 | — | — | T2(확장) |

> ❌가짜(강등)는 이 문서에서 전부 제외됨(killer 35개). 남은 killer는 ✅확실·❓불명확·🔶조건부만.
> **중요**: 칸은 purity로 묶였지만 killer/mine 확정은 purity가 아니라 **Δprob(개입·재추론)** 부호로 갈린다 — 같은 칸에 ✅와 ❓ 공존 가능. 매개는 Δprob>0 보편리프트가 전제라 별도 판정 없이 등급만 표기.

## 3유형은 어떻게 뽑았나 — 3층 필터

학습된 HIN-GNN(v2_sweepA) **단일 추론 1회**에서 키워드별 어텐션·라벨을 집계(관찰)하고, 의심분만 **재추론**(개입)으로 인과 검증한다.

```
1. 분류   (관찰, 단일추론)    purity·WoE·Score   → 성공/실패 특이성으로 1차 태깅
2. 빈도보정 (관찰, 단일추론)    빈도 floor·Wilson  → 소표본 거품 제거(공주 n=1 등)
3. Δprob검증 (개입, 재추론)    캐리어 고정+k 토글  → 유발/악재/보편 인과 확인
```

- **killer·mine = 2축**(성공특이 ↔ 실패특이), **매개 = 직교축**(특이성과 무관한 보편 리프트).
- **2단 등급**: T1(엄격 핵심) / T2(확장 후보). hub(무색무취 백본)는 내부 게이트라 출력 제외(= 중립).
- 상세 공식: `docs/keyword_classification_criteria.md`.

## 빈도밴드별 purity 중앙값 / 평균  (❌가짜 제외 후)

> 각 칸 = `중앙값 / 평균`

| 빈도 | killer | mine | 매개 |
|---|---|---|---|
| 니치(3-9) | 0.600 / 0.637 | 0.091 / 0.092 | 0.167 / 0.196 |
| 중(10-29) | 0.542 / 0.543 | 0.071 / 0.081 | 0.273 / 0.271 |
| 고(30-99) | 0.419 / 0.456 | 0.096 / 0.099 | 0.274 / 0.269 |
| 메가(100+) | 0.383 / 0.420 | 0.107 / 0.098 | 0.243 / 0.231 |

→ killer만 빈도 따라 단조 하락(base로 수렴 = 구체 라인→범용어). mine은 빈도 무관 저공(강건), 매개는 base 근처 평평(성공특이 아님).

## 축 기준

| 축 | 구간 |
|---|---|
| **빈도** | 니치 3–9 / 중 10–29 / 고 30–99 / 메가 100+ |
| **purity** (base 0.238) | 강성공 ≥.50 / 성공기울기 .35–.50 / 중립대 .18–.35 / 실패기울기 .10–.18 / 강실패 <.10 |

> killer·mine·매개 전수.

## 이 리포트 읽는 법

1. **세로축(purity)으로 유형, 가로축(빈도)으로 추상화 수준**을 읽는다.
   - killer = 성공특이(purity 높음). 빈도 낮을수록 *구체 라인/IP*(고창·빈츠), 높을수록 *범용 카테고리어*(빵·과자).
   - mine = 실패특이(purity 낮음). **빈도 무관 강건** — 고빈도일수록 오히려 더 큰 구조적 실패(와인 300/0.05).
   - 매개 = base 0.238 근처 + 어디든 +. **빈도 무관 평평**(특이성과 직교).
2. **마크로 신뢰도**: ✅ 안심 · ❓ 노이즈(보류) · 🔶 IP 있을 때만 · ⚠ 의심 / 매개 🟢T1 우선 · 🔵T2 확장후보.
3. **purity ≠ 처방효과.** purity는 "이 키워드 어텐션 중 성공제품 비중"(관찰)이고, 넣었을 때 오르나(Δprob, 개입)는 별개 축이다. 그래서 같은 칸에 ✅와 ❓가 공존한다.
4. **실무 매핑**:
   - 처방(넣어라): **killer 니치/중 × 강성공 ✅** (고창·하와이·미역·연유·페스츄리).
   - 회피(빼라): **mine 전부**, 특히 고빈도(와인·다이어트·하이볼·제육·갈비).
   - 범용 강화제: **매개 🟢T1** (즉석·저당·당충전·허쉬·고추).
   - 보류·재검: **❓ 마크 + killer 고/메가**(빵·과자·바삭류).
5. **해석 주의**: 시그니처는 추상 맛법칙이 아니라 **2025 제품 클러스터 성패의 학습**이다(고창=롯데 고창꿀고구마 라인). killer는 라인·브랜드 맥락과 함께, mine은 구조적이라 2026에도 유효, 매개는 트렌드라 분기 갱신.

## 매개 — 보편 증폭 (어디든 +)  (n=79)

등급 분포: 🔵T2 55 · 🟢T1 24
