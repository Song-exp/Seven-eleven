## 3. 논거

### 편입 찬성

- 하정우 와인은 **POS 압도적 1위** (183M원, 카테고리의 20.8%)로 명확한 성공 시그널
- 세븐일레븐 인스타에도 등장 (`POS+인스타` 소스)
- 현재 `npd_success_labels.csv`와 `_combined` 어디에도 성공으로 잡히지 않는 공백
- 인스타 좋아요합(316)이 낮아 인스타 채널로도 구제 불가

### 편입 반대

- **단일 제품 의존도 비정상**: 1위 제품 혼자 20.8%를 차지 → 파레토 기준 자체가 왜곡
- 편입 시 **244개 실패 제품** 추가 → GNN 학습 데이터 노이즈 증가
- 와인이 파레토 X였던 원인이 바로 이 구조적 특성일 가능성
- 카테고리 편입은 `00` Phase 0C 수정 → **전체 파이프라인 재실행** 필요

## 4. 절충안

카테고리 전체를 넣지 않고 **하정우 와인 1개만 성공 케이스로 수동 편입**하는 방법.

```python
# npd_success_labels.csv에 수동 추가 (예시)
manual_entry = {
    "ITEM_CD":  "126753",
    "상품명":   "하정우)마키키쇼비뇽블랑750ml",
    "중분류":   "와인",
    "소분류":   "화이트",
    "성공여부": "성공",   # 메모: 수동 편입, POS 30일 매출 1위 근거
}
```

| 방식 | 장점 | 단점 |
|---|---|---|
| 카테고리 전체 편입 | 일관된 기준 | 파이프라인 재실행, 노이즈 244개 |
| 수동 성공 편입 | 최소 변경, 노이즈 없음 | 기준 일관성 훼손 |
| 현행 유지 (미편입) | 변경 없음 | 명확한 성공 케이스 누락 |
