## 2. 주요 실험 단계별 요약 및 인사이트

### 2.1. 초기 베이스라인 및 하이퍼파라미터 튜닝 (exp01 ~ exp16)
* **주요 목표**: 기본적인 HIN 구조의 뼈대를 잡고, `hidden_dim`(64 vs 128), `pos_weight`(불균형 가중치), `lr`(학습률) 등을 튜닝하는 단계.
* **핵심 발견**:
  * 클래스 불균형 가중치 `pos_weight`를 3.24 정도로 조정하여 학습 손실을 고르게 반영하는 것이 성능 안정화에 기여함.
  * `hidden_dim`을 64로 조정한 설정(`exp16_hidden64` 등)이 128 설정보다 과적합이 덜 발생하고 Test 일반화 성능이 양호함을 확인.

### 2.2. 멀티홉 어텐션 및 키워드/IP 결합 임계 스윕 (exp18 ~ exp31)
* **주요 목표**: 멀티홉 메시지 전파 레이어를 도입하고, 노드 간 연결 밀도를 조정하기 위해 `kw_min_shared`와 `ip_min_shared` 임계값을 실험.
* **핵심 발견**:
  * `exp21_h64_on18` 모델이 0.6867의 Test PR-AUC를 기록하며 강력한 베이스라인으로 자리 잡음.
  * 키워드 공유 임계를 완화(`kw_min` 5 → 3)하면 연결 관계가 촘촘해지지만, 일부 실험에서는 오히려 노이즈가 증가하는 경향을 보여 최적 밀도 조절이 중요함을 확인.

### 2.3. Method B - 신규 간접 엣지 추가 및 격리 격자 실험 (exp32 ~ exp42)
* **주요 목표**: 기존 1홉 메시지 패싱이 해결하지 못하던 간접 경로(`P-I-K`, `P-I-IP-K`, `P-K-K`)를 사전 계산하여 엣지로 연결하고, 최적 조합(엣지 종류 × kw_min × ip_min) 격자 스윕 후 hidden_dim 및 kw 임계 세부 탐색 진행.
* **핵심 발견**:
  * **격자 구조**: 3 엣지 조건(no new / +via+ipip / +all) × 2 kw(5,3) × 2 ip(2,1) = 12셀. +all 행이 kw↓ ip↓ 할수록 단조 증가(0.6659→0.6762→0.6881→0.6959) → 새 엣지는 base 그래프가 촘촘할 때 효과적.
  * **격자 Winner**: **`exp41_trend_kw3_ip1`** (+all new edges, `kw_min=3`, `ip_min=1`, `h=64`) 모델이 **Test PR-AUC 0.6959**를 달성하여 프로젝트 최고 성능을 경신함.
  * **Phase A (hidden_dim)**: 동일 설정에서 h=128(exp35) 시도 → val은 소폭 상승(+0.008)하나 test 하락(-0.012) + val-test gap 0.033→0.053 확대. 과적합 확인 → **h=64 확정**.
  * **Phase B (kw 임계 세부 탐색)**: kw=2(exp42) 시도 → test 0.6959→0.6858로 하락, gap 0.033→0.046으로 기준선(0.040) 초과. kw=1은 sim_kw 엣지 조합론적 폭증으로 GPU OOM → **kw=3이 sweet spot**.
  * **최종 확정 모델**: `exp41_trend_kw3_ip1` — +all, kw=3, ip=1, h=64, test PR-AUC=**0.6959**, val-test gap=0.033.

### 2.4. α_r 분화 개선 시도 및 공동구매 엣지 기여도 분석 (exp44 ~ exp47)
* **주요 목표**: DiffMG 게이트가 키워드 4개 경로(has_kw / via_ip / ipip / trend)에서 α_r≈1/24로 균등 수렴한 원인을 해소하여 관계 중요도 해석력을 높이는 방법 탐색.
* **실험 구성**:
  * **exp44** (`use_lift_weights: true`): Lift 수치를 edge_attr로 활성화 → co_offline α 0.131→0.161로 오히려 증가, test 0.6959→0.6741 하락. 키워드 α_r std=0.0 변화 없음.
  * **exp45** (`lr_alpha: 0.05`, `temperature: 0.2`): 게이트 학습 강화 → co_offline α 0.897로 폭주, test 0.6610 (최악 일반화). 키워드 α_r std=0.0 변화 없음.
  * **exp46** (exp44+exp45 동시): test 0.6375 (전체 최저). 두 효과 충돌.
  * **exp47** (`co_offline·co_quick 제거`): test 0.5699 (exp41 대비 **−0.126**), val-test gap 0.008로 수렴. 키워드 α_r std=0.0 **여전히 변화 없음**.
* **핵심 발견**:
  * co_offline + co_quick 2개 관계가 예측력의 핵심 — 제거 시 PR-AUC 0.126 급락.
  * 키워드 경로 균등 수렴의 원인은 co_offline 지배가 아니라 **랜덤 키워드 임베딩** — 4경로가 구조적으로 구분 불가능하여 어떤 개입으로도 분화 불가.
  * α_r 분화를 위해서는 키워드 임베딩 초기화 방식(random → content-based)을 변경해야 함 (현재 범위 밖).
* **결론**: 4가지 실험 모두 exp41 대비 성능 또는 일반화 기준 미달 → **exp41 최종 확정 유지**.
