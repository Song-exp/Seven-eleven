# IP-IP 엣지 확장을 위한 신규 IP 속성 추출 계획

## 목적

현재 HIN 그래프 구조:
```
제품 → IP → 키워드(속성)
```

목표 구조:
```
제품 → IP₁ → IP₂(키워드) → IP₂의 속성
```

기존 IP 노드(`ip_nodes_final.parquet`)의 `키워드_final` 목록에 **IP 이름 자체**가 키워드로 들어있는 경우,  
해당 키워드-IP에 속성을 부여하면 IP-IP 엣지를 통한 더 깊은 그래프 탐색이 가능해짐.

---

## 분석 방법

1. `ip_nodes_final.parquet`의 전체 키워드 추출 (470개 후보)
2. 이 중 ip_set에 미등록된 고유명사 필터링
3. 사용자 추가 후보 병합 및 ip_set 교차 확인

## 키워드에 없어 IP-IP 연결 불가 (2개)

| 키워드 | 비고 |
|---|---|
| `다오` | 어떤 IP 키워드에도 없음 — 카트라이더 캐릭터 |
| `브로디` | 어떤 IP 키워드에도 없음 — 카트라이더 캐릭터 |

추가하려면 먼저 `카트라이더러쉬플러스` 키워드에 직접 삽입 필요.

## 제외 확정 (속성 추출 불필요)

| 항목 | 이유 |
|---|---|
| 신과함께, 베를린, 추격자 | 하정우 IP 하위 영화 제목 — 하정우로 충분히 커버 |
| 루피 | 잔망루피 IP 키워드로만 등장 (원피스 캐릭터 아님) |
| 다오, 브로디 | 어떤 IP 키워드에도 없음 — IP-IP 연결 불가 |
