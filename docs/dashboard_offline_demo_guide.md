# 오프라인 데모 사용 가이드 — `dashboard_offline.html`

> **무엇:** 서버·인터넷 없이 더블클릭으로 도는 **자체 완결 단일 HTML**(약 1.06MB).
> **값의 출처:** 라이브 백엔드(`/combo`·`/infer`·`/insight/filter`)를 실제로 한 번 돌려 **freeze**한 값. 화면 숫자·키워드는 라이브와 동일.
> **파일 위치:** `Dashboard/dashboard_offline.html`

## 1. AI 요약 인사이트 — 색/태그 의미 (먼저 외울 치트시트)

데모 중 "각 단어가 무슨 의미냐"를 설명할 때 쓰는 표.

### gtag — 키워드의 역할 (네트워크 전체 기준, 2025 prior)
| 표기 | 색 | 의미 |
|---|---|---|
| 🔑 **흥행**(killer) | 초록 | 비슷한 키워드를 쓴 신상품이 **성공한 경우가 많음**. 단독으로도 성공확률↑ |
| ⚠ **주의**(mine) | 빨강 | **실패에 쏠린** 키워드. 금지룰 아님 — 강한 흥행·조합으로 상쇄 가능 |
| 🧪 **매개**(bridge) | 보라 | 혼자선 약해도 **어디 붙여도** 성공확률을 올리는 보편 증폭제 |
| ◽ **일반**(hub/무태그) | 회색 | 성패에 중립인 범용 백본 |

### ctag — 채널 (어디서 성공을 유발하나)
| 표기 | 색 | 의미 |
|---|---|---|
| 🩷 **인스타** (인스타형·범용) | 핑크 | **온라인 바이럴(인스타) 성공 유발** → 초기 마케팅 카피·해시태그 |
| 🟢 **POS형** | 초록 | **오프라인 매출(POS) 성공 유발** → 제품 스펙·내실 |

### 노드 색 (네트워크 그림)
- 초록 = 속성 키워드 / **노랑·주황 = IP(콜라보 대상)** / 빨강 = 제품

## 2. 데모 시나리오 3종 (정확한 클릭 + 실제로 뜨는 값)

### 🥟 시나리오 1 — 호박 인절미 *(기능 풀투어)*

**STEP 1.** 검색창에 **`호박 인절미`** 입력 → 칩 중 **`단호박` · `인절미` · `달콤`** 선택 → 네트워크 생성
> 칩 후보: 단호박·인절미·고소·쫄깃함·꾸덕함·달콤·구수함·쌀·찹쌀·간식·디저트·전통·한식·가을

**STEP 2.** 우측 **🎯 AI 요약 인사이트** 읽기 (각 색의 의미를 위 치트시트로 설명)
```
🎯 호박인절미라는 검색어를 매칭된 키워드 단호박·인절미·달콤으로 조합해봤어요.
📍 고소·맘모스·샌드·한정·촉촉을 중심으로 기획해보세요.
📍 포켓몬스터·맘모스·폭신함은 인스타에서 바이럴이 잘 돼요.
📍 네트워크에서 흥행을 끌어올리는 연세우유·폭신함, 두루 어울리는 포켓몬스터…,
   콜라보하기 좋은 푸하하소금빵·키키블룸도 참고해보면 좋아요.
```
*(샐러드·상큼 등 무관 키워드 52개는 LLM 필터로 제거된 상태 — freeze됨)*

**STEP 3.** 시드 **`인절미`** 노드 클릭
> 설명: *"네트워크 내에서 시너지를 망치지 않으면서 가장 연결이 잘 되는 조합(rail)이며, 이 경로를 따라 네트워크를 구성한다."*
> rail = **인절미 → 달콤 → 맘모스 → 샌드 → 고소**

**STEP 4.** AI 인사이트(또는 네트워크)에서 **`맘모스`** 클릭 → 우측 패널
> - 맘모스 = **◽일반(역할 무색무취) + 🩷인스타형(바이럴 키워드)**
> - 주변에 붙는 키워드(함께 등장)·궁합 후보 표시

**STEP 5.** 맘모스 누른 상태로 **`샌드`** 클릭 → 우측에 궁합
```
✅ 두 키워드를 조합하면 성공 가능성 +3.4%
```
*(맘모스×샌드 = margin 0.0341, 베이크된 시너지 행렬에서 — 라이브 없이 표시)*

**STEP 6.** 네트워크 전반 설명
> 노랑 **IP** 노드(세이카·노티드·뉴진스·BT21·버터베어·연세우유 등)가 붙어 있고,
> **연결된 모든 키워드 간 관계를 한눈에** 파악할 수 있다.

---

### 🍫 시나리오 2 — 두바이 *(차별화 + 인스타/POS 채널)*

**STEP 1.** **`두바이`** 검색 → 칩에서 **`두바이`** 선택 *(이 시나리오는 두바이 단일 선택으로 freeze)*
> 칩 후보: 두바이·피스타치오·카다이프·초코·고소·달콤·바삭·쫀득함

**STEP 2.** rail 읽기 = **두바이 → 카다이프 → 말차 → 소르베 → 케이크** (두바이 초콜릿 해부도)
- AI 인사이트: 🔑 **커스터드**(흥행) / ◽ **카다이프🩷·케이크🩷**(일반·인스타) / 🩷 인스타: 카다이프·커스터드·소르베

**STEP 3.** 비-뻔한 조합 시연 (노드 클릭 → 클릭)
```
카다이프 × 말차    → ✅ +0.7%  (말차 두바이 — 의외의 보완)
카다이프 × 커스터드 → ✅ +11%   (바삭+크림 식감 대비, 최강)
```
> 멘트: *"남들 다 하는 피스타치오 두바이 대신, 네트워크는 **말차 두바이**를 보완으로 집어준다."*
> *(피스타치오×말차 ⚠대체 비교는 교차쌍이라 오프라인 미표시 → 말로만 설명)*

**STEP 4.** 채널 분리 + IP
> 📸 인스타: 카다이프·커스터드·소르베 / 🛒 POS: 녹음·망고 / 노랑 IP: 배스킨라빈스·성심당·당과점

---

### 🌶 시나리오 3 — 마라 *(뻔한 함정 회피 + 셰프 IP)*

**STEP 1.** **`마라`** 검색 → 칩에서 **`마라`** 선택 *(단일 선택으로 freeze)*
> 칩 후보: 마라·고추·마늘·매콤·얼큰함·자극적·중독성·화끈함

**STEP 2.** rail = **마라 → 누들 → 짭조름함 → 콜라보 → 라면**
> 멘트: *"마라 = 국물(탕)이 아니라 **누들·볶음 라면 + 콜라보**가 정답 형태."* (누들 margin +12.5%로 최상위)

**STEP 3.** ⚠ **주의(mine)** 노드 = **`탕` · `육수`** (빨강)
> 멘트: *"국물형 마라탕은 **실패 특이(mine)** — 이 방향은 피하라."* ← mine의 가치를 보여주는 장면

**STEP 4.** 노랑 IP = **여경래 · 만찢남** (흑백요리사 중식셰프)
> 멘트: *"셰프 IP 콜라보로 확장 가능."*

## 3. 오프라인에서 **되는 것 / 안 되는 것**

| ✅ 된다 | ❌ 안 된다 (라이브 전용) |
|---|---|
| 위 3개 검색어 → 칩 | 그 외 **임의 검색어** (LLM /infer 필요) |
| 칩 선택 → 병합 네트워크 | — |
| AI 요약 인사이트 (필터 적용된 깔끔 버전) | 위 3개 외 **다른 선택 조합**의 필터(잡 키워드 더 낌) |
| **키워드×키워드** 궁합 %p (맘모스×샌드 +3.4% 등) | **키워드×IP** 궁합 (설계상 라이브 전용) |
| 흥행/주의/매개/일반 + 🩷인스타/🟢POS 태그 | 교차쌍 (예: 피스타치오×말차 — 다른 시드 노드) |
| 노드 클릭·인접·IP·rail | |

> **데모 수칙:** 각 시나리오의 **정확한 검색어와 선택**만 따라가세요. 다른 조합을 고르면 네트워크는 떠도 인사이트 필터가 안 걸려 키워드가 지저분해집니다.

## 4. 재생성 / 업데이트 방법 (값을 새로 freeze하고 싶을 때)

원본(`dashboard.html`)은 라이브 전용이고, 오프라인은 **별도 빌드 파일**입니다. 모델·데이터가 바뀌어 값을 갱신하려면:

1. 라이브 서버 가동 (`python -m uvicorn src.eval.api:app --port 8000`)
2. 시나리오별 **`/combo`(시드) · `/infer`(검색어) · `/insight/filter`(선택조합 drop set)** 캡처
3. 캡처값을 `dashboard.html`에 인라인(vis-network 벤더 + COMBO_DATA + OFFLINE + API_BASE='') → `dashboard_offline.html` 생성
   - 검색칩 폴백: `apiInfer` → `window.OFFLINE.trendAttrs`
   - 인사이트 필터 폴백: `apiInsightFilter` → `window.OFFLINE.insightDrop[정렬된 선택.join('|')]`

> **현재 freeze된 것:** 시드 `인절미·단호박·달콤·두바이·마라` / 검색어 `호박 인절미·두바이·마라` / drop set `단호박|달콤|인절미·두바이·마라`

### (선택) 완전 air-gap
지금은 **폰트만** CDN(Pretendard·Noto Sans KR)에서 로드. 무인터넷에서도 폰트까지 동일하게 하려면 폰트 파일을 `vendor/`에 받아 인라인하면 됨. *(기능엔 영향 없음)*
