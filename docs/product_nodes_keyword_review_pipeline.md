## Step 1 — 마스터 병합 (`merge_keyword_review_final.py`)

### 처리 순서

1. **마스터 중복 제거**: 동일 제품명 2개 이상인 3건을 첫 행만 유지
   - `짐빔파인애플`, `짐빔허니`, `달너새랜덤초코과자`
2. **★베스트바구니 제거**: 마스터에서 해당 행 삭제 (검수 대상 외 항목)
3. **스마일메롱바 → 메롱바** 이름 매핑 (개인 파일의 표기 통일)
4. **개인 파일 중복 통합**: 동일 제품명이 복수 파일에 존재하면 컬럼별 병합 규칙 적용
5. **마스터 × 개인 파일 병합**: `merge_two_vals()` 함수로 컬럼별 적용

### 병합 규칙 (`merge_two_vals`)

| 마스터 값 | 개인 값 | 결과 |
|---|---|---|
| 빈값 | 빈값 | NaN |
| 빈값 | 텍스트 | 개인 값 |
| 텍스트 | 빈값 | 마스터 값 |
| O | 텍스트 | 텍스트 (개인 값 우선) |
| 텍스트 | O | 텍스트 (마스터 값 우선) |
| 텍스트 A | 텍스트 B | `A, B` 쉼표 합치기 (중복 제거, 순서 유지) |

### 출력

`product_nodes_keyword_analysis_검토_final.csv` — 5,136행

> 팀원이 비워둔 233행은 작업자가 수동으로 직접 보완하여 최종적으로 공란 0개 상태.

## Step 2 — 키워드 확정 (`build_product_final_keywords.py`)

### 4컬럼 조합 규칙

`관련있음`, `관련없음`, `살릴키워드`, `죽일키워드` 네 컬럼을 조합하여 최종 키워드를 결정한다.

| 케이스 | 살릴키워드 | 죽일키워드 | 결과 |
|---|---|---|---|
| A | O | 없음 | `관련있음` 전체 |
| B | O | 있음 | `관련있음 − 죽일` |
| C | 텍스트 | 없음 | `관련있음 ∪ 살릴` |
| D | 텍스트 | 있음 | `(관련있음 ∪ 살릴) − 죽일` |
| F | 빈값 | 없음 | `관련있음` 전체 |
| G | 빈값 | 있음 | `관련있음 − 죽일` |
| — | **제거** | — | **행 자체 삭제** |

### 추가 처리

- **프로모션 코드 자동 제거**: `^\d{3,4}\s*:` 패턴 필터 (예: `0106 : 단품할인` → 제거)
- **행 제거 조건**: 살릴키워드 = `제거` (85개) + 제품명 = `제거` (2개) = **87개 삭제**
- **상품명 수정** (3건):
  - `주)백종원스페셜우삼격` → `주)백종원스페셜우삼겹`
  - `간장계란소스` → `돈키호테간장계란소스`
  - `유자후추` → `굵게간유자후추`
- **ITEM_CD 매핑**: `product_nodes.parquet`의 `ITEM_NM → ITEM_CD` 딕셔너리 기준. 수정된 상품명은 구 이름으로 역방향 조회.

## Step 3 — product_nodes.parquet 갱신 (미완)

`product_final_keywords.csv` 기준으로 아래 작업이 남아 있다.

1. **`키워드_final` 컬럼 갱신**: `product_nodes.parquet`의 각 제품 행에 확정 키워드 덮어쓰기
2. **삭제 제품 87개 제거**: `살릴=제거` + `제품명=제거` 행을 `product_nodes.parquet`에서도 제거
3. **상품명 수정 3건 반영**: `ITEM_NM` 컬럼 값 교정
4. **`product_keyword_edges.parquet` 재생성**: 갱신된 `키워드_final` explode → `ITEM_CD | keyword`

## IP 처리 ★ 완료 (2026-06-10)

`product_final_keywords.csv`의 IP 컬럼은 두 단계로 처리 완료.

### 1단계 — 표기 정규화 (product_final_keywords.csv)

| 원본 표기 | 정규화 후 |
|---|---|
| `부장이야기` | `서울자가에대기업다니는김부장이야기` |
| `ML` | `KBO` |
| `장우(이장우?)` | `이장우` |
| `헬로키티` | `산리오캐릭터즈` |
| `FC모바일??` | `FC모바일` |
| `MLB, 니베아, 산리오` | 행 분리 → `KBO`, `니베아`, `산리오캐릭터즈` 각각 |

무시 처리 항목 (메모성/비IP): `csv에 상품누락`, `csv에 ip 누락(집대성)`, `뭔지 모르겠는데...`, `초코`, `우롱차`, `커스터드`, `버블검, 껌`, `링티`, `스타벅스`, `이삭토스트`, `정성시리즈`, `풀무원`

마스터 신규 추가 IP: `이장우`, `혜자`, `권성준`, `잔망루피`, `도라에몽`, `메탈카드봇`, `FC모바일`

### 2단계 — IP 마스터(product_ip_mapping.xlsx Sheet1) → product_final_keywords.csv 대응

Sheet1의 제품명:매칭_IP를 product_final_keywords.csv 제품명 기준으로 join하여 IP 컬럼 채움.

| 항목 | 수치 |
|---|---|
| IP 신규 채움 | 1,006건 |
| 충돌 덮어쓰기 | 3건 |
| **IP 있는 제품 (최종)** | **1,065행 / 5,051행** |

**IP 마스터 기준 파일**: `data/processed/hin/최종/product_ip_mapping.xlsx`
