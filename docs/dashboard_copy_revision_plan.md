## E-2. 브리핑 패널 — 키워드 1개 클릭 (`_comboBrief`)

> 목표: 패널을 대폭 단순화. **[키워드명] → [성격 설명 문장(색)] → (인스타면) [핑크 한 줄] → [함께 등장하는 것 표]** 만 남김.

| # | 위치 | 변경 |
|---|---|---|
| E2-1 | 노드 부제 (`.sub`: IP / 시작 속성 / 속성 키워드) | **삭제** (노드 색으로 구분되므로) |
| E2-2 | 키워드명 옆 태그 배지 (`_gtagBadge` 🧪 매개 키워드 등) | **삭제** |
| E2-3 | "이 키워드의 성격" 섹션 헤더 (`_gtagRow`) | 헤더 **삭제** → **성격 설명 문장만** 표시 (색=역할, 이모티콘 없음) |
| E2-4 | "어디서 통할까" 섹션 헤더 (`_ctagRow`) | **삭제** |
| E2-5 | 채널 POS형/매장형 (배지+설명) | **완전 삭제** |
| E2-6 | 채널 인스타 설명 | **"인스타에서 바이럴되기 좋은 키워드예요."** 한 줄만, **핑크(#BE185D)** · (표본 적음 참고 문구도 삭제) |
| E2-7 | "이 속성은 정밀 궁합 계산 대상이 아니에요…" | **삭제** |
| E2-8 | 시드/비시드 섹션 (✅이 속성에 잘 붙는 것 / ⚠같이 쓰면 손해 / ✅잘 어울리는 속성 / ⚠잘 안 맞는 속성) | **전부 삭제** |
| E2-9 | **"함께 등장하는 것" 표** | **유지** (단, 엣지 사유 텍스트는 F-3에서 제거 → 이름 + 관련도 강도바만) |

**최종 구성**: `키워드명` → `성격 설명 문장(흥행=초록 / 주의=빨강 / 매개=보라)` → (인스타면) `핑크 한 줄` → `함께 등장하는 것(+관련도)`

## F. 태그 / 사유 / 등급 사전

| # | 대상 | 변경 |
|---|---|---|
| F-1 | 키워드 성격 (`GTAG_INFO`) | **이모티콘 제거, 색으로만 표시**, 배지(직접 태그명) 대신 **설명 문장**으로 대체 (= E2-2·E2-3) |
| F-2 | 채널 (`CTAG_INFO`) | **POS형 미표시**, **인스타만** 표시 (= E2-6, 핑크 한 줄) |
| F-3 | 엣지 사유 (`EDGE_WHY`) | **삭제** ("함께 등장하는 것" 표에서 사유 텍스트 제거 → 관련도 강도바만 남김) |
| F-4 | 시너지 등급 (`_synTier`) | **관련도 반영** — D 범례에서 정한 "관련성" 개념을 등급/표시에 반영 |

- ⚠ **확인 필요(F-4)**: "시너지 등급에 관련도 추가"의 정확한 형태 — (a) "함께 등장" 강도바를 **관련도**로 명명만 / (b) 시너지 표시 옆에 관련도(연결강도) 수치 병기 / (c) 등급 라벨 자체 변경. 기본 해석은 (a)+(b). 적용 직전 확정 요망.
- 참고(요청대로 계획엔 미반영): **엣지 사유(EDGE_WHY)는 "엣지 타입(관계 종류)" 기준** — 백엔드 HIN 엣지 type(rail/basket/trend/ip/anti 등)을 사람이 읽는 말로 매핑한 것(점수 아님). → 별도 답변 참조.
