# synergy — headroom 회복분이라 단독강도와 음의 상관, realized success와 역전

- 모델: **v2_sweepA** | 날짜: 2026-06-22 | 태그: 방법론/해석 주의
- 도구: `eda/synergy_threshold_eda.py` (E1~E8) — 시드별 서브넷 synergy 분류 + 실제 성공률 앵커
- 배경: 처방 `💉 시너지`·`⚠ 잠식` 라벨의 기준(per-pair 2·SE)을 검증하다, synergy가 *실제로 잘 붙는지*를 공동보유 제품 성공률로 앵커링(E7)한 결과에서 출발

## 관찰

**synergy 정의**: `synergy = margin(k|seed) − margin(k|∅)` = 키워드 k를 혼자 쓸 때 대비 시드 컨셉에 더했을 때의 추가 효과. per-pair 분류는 `|synergy| > 2·SE`(쌍별 노이즈 바닥).

**E7 — 실제 공동보유 제품 raw 성공률 (모델 prob 아님, base=0.238)**
| 분류 | 공동성공률(mean) | n쌍(공동≥3) |
|---|---|---|
| 시너지 | **0.245** | 18 |
| 보통 | 0.331 | 35 |
| 잠식 | **0.445** | 27 |

→ 기대(시너지 > base > 잠식)와 **역전**. 시너지로 분류된 쌍의 실제 성공률이 가장 낮음.

**E8 — 단독강도로 분해 (전 시드 354쌍)**
| 분류 | model baseline | 이웃 단독성공률 | 공동성공률 | n |
|---|---|---|---|---|
| 시너지 | **−0.033** | **0.254** | 0.245 | 133 |
| 보통 | −0.005 | 0.329 | 0.331 | 176 |
| 잠식 | **+0.033** | **0.403** | 0.445 | 45 |

상관:
- `corr(synergy, baseline) = −0.61` (강한 음)
- `corr(baseline, 이웃_단독성공률) = +0.42`
- `corr(synergy, 이웃_단독성공률) = −0.25`

## 해석

**synergy와 realized success는 구조적으로 반대다.**

- synergy는 키워드가 **혼자선 약할 때(baseline 낮음/음수 = headroom 있음)** 시드가 끌어올리는 "회복분"으로 커진다. → `corr(synergy, baseline) = −0.61`.
- realized success(공동보유 제품 성공률)는 키워드가 **혼자서 이미 강할 때** 높다. → `corr(baseline, 단독성공률) = +0.42`.
- 따라서 **synergy ↑ ⟺ 단독 약함 ⟺ realized success ↓** → E7 역전은 버그가 아니라 **정의상 당연**.

구체:
- **시너지 쌍** = 단독 약한 키워드(순대 baseline −0.061 등)를 시드가 구제 → 실제 성공률 낮음(0.25).
- **잠식 쌍** = 단독 강한 키워드(누들 baseline +0.157 등)를 시드가 희석 → 그래도 원판이 강해 실제 성공률 높음(0.45).

즉 **synergy = "약한 걸 살리는 잠재력(salvage)" 신호이지 "흥행" 신호가 아니다.** 강한 키워드는 올릴 여지가 없어 synergy가 낮고 종종 잠식으로 뜨지만, 그 조합의 실제 성공률은 오히려 높다.

> ⚠ E7의 외적 타당성 검증 자체의 한계도 병기: 공동보유 제품이 쌍당 ~3-5개로 희소(노이즈 큼) + synergy는 headroom(애매 제품) 한계효과 = *미래 반사실*인데 공동성공률은 *과거 실현* → 모집단 불일치. synergy의 진짜 외적검증은 신규 출시 A/B여야 함.

## 확정 함의

- **MD 해석 주의 (대시보드·처방)**: `💉 시너지`를 "이 조합은 흥행"으로 읽으면 안 됨. "그 속성이 *혼자선 약한데* 이 시드가 살려준다"는 뜻. **baseline(단독실력)을 한 칸 병기**해야 "약한 걸 살리는 조합 vs 강한 걸 합치는 조합"을 구분한다.
- **분류 기준(per-pair 2·SE) 자체는 유효**(E1~E6, 특히 E4 포화 시드 전부 '보통'으로 정직 처리). 바뀌는 건 *해석*이지 기준이 아님.
- 처방 `synergy_within`/`explain` 출력에 **baseline·단독성공률 컬럼 추가** 검토. [[md_prescription_system_guide]] §3의 "modifier vs base 강도"와 동일 정신([[2026-06-21_고창-modifier-vs-base]]: 고창=증폭기, 진짜 드라이버는 base).

### ★ 패스 구성 가드레일 — 두 그리디는 반대 함정

synergy가 단독강도와 음의 상관(−0.61)이므로, **무엇으로 패스를 키우느냐**가 결과를 가른다:

| 방식 | 고르는 것 | 함정 |
|---|---|---|
| **절대 margin** (`combo_grow` 레일, `delta_mean`) | 강한 키워드 | 증폭기 쌓기·포화 ([[2026-06-21_조합-포화-substitution]]) |
| **synergy** (`revive`·`explain`·combo_grow의 `★찐보완재(emergent)` 라벨) | 단독 약한데 살아나는 것 | **약체 체이닝** (단독 약한 노드끼리 묶임) |

- `combo_grow` **레일 성장**은 절대 margin 기준이라 약체 체이닝은 안 함. 그러나 거기 붙는 **`★찐보완재(emergent)` 라벨은 synergy>0** = 단독 약체 salvage일 수 있음 → 라벨만 보고 "좋은 조합"으로 오해 금지.
- 내가 synergy로 바꾼 **`revive`(서브넷 보강/대체)·`explain`** 출력은 *대놓고 synergy 그리디* → **약체 체이닝 위험이 실제로 여기 있음**.
- **가드레일**: 패스/조합 평가에 **노드 단독성공률 + 패스 평균 단독성공률**을 병기. 낮으면 "약체끼리 모인 salvage 체인" 경고.
- **원칙**: synergy(협응) ⟂ 절대강도(실력) 직교. **둘 다 높은 패스가 진짜 좋은 조합.** synergy만 높으면 salvage, 절대만 높으면 amplifier 더미. 한 축만으로 패스를 키우지 말 것.

### ★ killer × killer = 시너지 없음 (포화) — 직접 실증 (2026-06-22)

WoE-killer는 **단독성공률이 높다**(mean 0.648 / median 0.722 vs base 0.238 = base의 ~3배). 단독 강함 = headroom 없음 → killer끼리 묶으면 시너지가 안 나야 한다. **강 killer 5개(공룡·공주·나폴리탄·뷰티·여유, 단독 1.0) 전 쌍(10) synergy:**

| | synergy |
|---|---|
| 잠식(≤0) | **8쌍** |
| 노이즈(0<·<+0.01) | 2쌍 (+0.0035, +0.0099) |
| 진짜 시너지(>2·SE) | **0쌍** |

→ **단독 강한 killer끼리는 시너지 0** (포화·자기잠식). 도구: `src/eval/md/review.py`(`solo_success` 컬럼) + `subnet.pair_synergy`.

**처방 규칙**: 강 killer + 강 killer ✗ (포화) / 강 killer(base) + 약 modifier(headroom) ✓ (시너지). → killer 평가에 **단독성공률을 필수 2번째 축**으로 병기(Δprob=유발만으론 조합 예측 불가).

## 부록 — synergy 분류 기준 (per-pair 2·SE)

분류는 **두 관문(방향 + 유의성)**을 통과해야 시너지/잠식으로 확정된다.

**① baseline 빼기 = 결합 효과만 분리 (방향)**
```
synergy = margin(k|seed) − margin(k|단독)
                            └ baseline(키워드 단독효과) 제거
```
baseline을 빼는 건 "k가 혼자서도 했을 몫"을 걷어내, **순수하게 '같이 묶어 생긴 추가분'**만 남기기 위함. 부호가 방향:
- `+` = 단독보다 더 오름(시너지 후보) / `−` = 내림(잠식 후보).

**② 2·SE 비교 = 그 추가분이 우연 아님 (유의성)**
synergy는 **제품 n개(headroom) 표본의 평균**이라, 다른 표본을 뽑으면 값이 흔들린다. 그 흔들림 = `SE = std(per-product synergy)/√n`. "흔들리는 저울" 비유:
- 저울이 ±1kg 떨리는데 "+0.3kg" → 떨림에 묻힘 → 진짜인지 모름 = **보통**
- "+5kg" → 떨림보다 훨씬 큼 → 진짜 = **확정**

여기서 측정값=synergy, 떨림=2·SE. 즉 **"이 결합효과가 잴 때의 잡음보다 큰가?"**를 측정 자신의 떨림으로 판정.

**최종 규칙**
```
synergy > +2·SE  →  시너지   (오름 + 유의)
synergy < −2·SE  →  잠식    (내림 + 유의)
|synergy| ≤ 2·SE →  보통    (유의하지 않음, 부호 무관)
```
실측(마라+탕): synergy +0.019 vs 2·SE 0.012 → 0.019>0.012 → **시너지**.

> ★ 커트라인(2·SE)은 **단독 성공률의 분산이 아니다.** synergy를 잰 *그 표본 안에서 synergy가 흔들리는 폭*(per-pair self-noise)이다. 단독 성공률(E7·E8)은 외적 타당성 검증용 별개 신호. 또한 이 "우연 아님"은 **통계적 유의성**일 뿐, **흥행 보장이 아님**(salvage이지 hit 아님 — 위 해석 참조).
