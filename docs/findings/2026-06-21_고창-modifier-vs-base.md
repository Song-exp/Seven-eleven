# 고창 — 성공을 가르는 건 고창이 아니라 캐리어 base 강도

- 모델: exp47 | 날짜: 2026-06-21 | 태그: killer (유지)
- 도구: `keyword_context_breakdown`, `keyword_disentangle` (노트북 §3.5)
- 발단: §3 드릴다운에서 "고창꿀고구마" 5개 제품 중 말랑카우만 실패 → 같은 속성인데 왜 갈리나?

## 해석
- **예상(고창이 비스킷엔 +, 캔디엔 −)은 틀림.** contrib은 실패한 말랑카우에서 오히려 더 높다.
- 진짜 구조 = **캐리어 base 강도 × 고창의 일정 리프트**:
  - 빈츠·카스타드: base 이미 0.9+ → 고창 빼도 안 떨어짐(contrib≈0). 고창이 일 안 하고 브랜드가 캐리.
  - 마가렛트·찰떡파이·말랑카우: 고창이 +0.3쯤 끌어올림. 비스킷은 base가 받쳐줘 THR 돌파. **말랑카우는 base(소프트캔디)가 너무 약해 0.04→0.335로 올려도 미달.**
- 고창은 **증폭기(modifier)이되 충분조건은 아님** — 약한 캐리어는 못 살린다.
- 교란 분리: `꿀고구마`는 신호 0~음수. **지역 브랜딩 '고창'이 실제 드라이버**, 맛 속성은 무임승차.

## 확정 함의
- 고창 = **killer 유지 타당** (일관된 +리프트).
- `keyword_final.csv` 메모에 "충분조건 아님 — 받쳐주는 캐리어(base 강한 비스킷류)에 붙일 것" 남기기 → MD가 조건부로 읽음.
- 일반화 가설: **지역명/IP 같은 브랜딩 키워드는 "일정 리프트형 증폭기"**일 가능성 → 다른 지역명(공주·남도 등)도 같은 패턴인지 §3.5로 확인해볼 것.

## caveat
contrib은 `score_concept`의 키워드-only 가상 트윈 기준(IP/프로모 채널 제외). `prob` 컬럼(실노드)과 절대값은 다르나, 차분이라 키워드 채널 기여는 일관되게 분리됨.
