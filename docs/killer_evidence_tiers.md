# killer 발표 신뢰도 등급 — 성공률 해석 레이어

> 모델 HIN-GNN(v2_sweepA) · 생성 2026-06-23 · 짝 문서: `keyword_frequency_purity_groups.md` · `keyword_examples_by_metric.md`
> **키워드 풀은 안 바뀐다.** killer/mine/매개 분류는 그대로(killer 89·mine 70·매개 79, ❌가짜 제외).
> 여기에 **raw 직접성공률 + Wilson 하한**을 덧붙여 *발표 신뢰도 등급*만 추가한다. 성공률 기준으로 새로 들어오거나 빠지는 키워드는 실질 0개.

---

## 0. 왜 이 레이어가 필요한가

killer는 purity(어텐션)·Δprob(인과)로 뽑혔지만, **직접 제품의 raw 성공률은 별개**다. 
예: `족발`은 purity 0.75·Δprob>0로 killer지만 직접 제품은 3성공/3실패(raw 0.50). 
MD 발표에서 "성공 키워드"라며 50/50 제품을 보여주면 설득력이 약하다. → **raw 성공률로 발표 등급을 나눠** 헤드라인용과 잠재신호용을 구분한다.

## 1. base rate = 0.238 — 모든 기준의 앵커

| 정의 | 값 |
|---|---|
| 글로벌 base = 전체 제품 성공률 (1197/5033) | **0.238** |
| 키워드별 직접성공률 평균 (빈도≥10) | 0.236 (≈ 일치) |

- **"보통 한 키워드에 붙은 제품은 4개 중 1개(~24%)만 성공한다"** = base. 두 정의(글로벌·키워드별평균)가 0.238로 수렴.
- 빈도≥5 키워드 직접성공률 분포: 중앙값 0.22, **90 percentile = 0.50** → raw>0.5는 **전체 키워드 상위 8%**.

## 2. 세 증거 축 — 서로 다른 질문

| 지표 | 답하는 질문 | 성격 |
|---|---|---|
| **raw 직접성공률** | 그 키워드 단 제품이 실제로 성공했나 | 실증 (발표 노출값, 교란 포함) |
| **Wilson 하한** | 그 실증이 표본 우연 아닌가 | 통계 (소표본 보정) |
| **Δprob** | 넣어서 성공확률을 올렸나 | 인과 (교란 제거, 기존 판정) |

### 2.5 Wilson 하한이란

**"표본이 작은 걸 감안한, 믿을 수 있는 최소 성공률."** 비율(proportion)의 95% 신뢰구간 하한(Wilson score interval, 1927).

성공률 50%라도 *2번 중 1번*과 *100번 중 50번*은 신뢰도가 다르다. 단순 성공률은 둘 다 0.50으로 같지만, Wilson 하한은 **표본이 적으면 값을 base 쪽으로 깎아내려** "이 정도는 진짜 보장된다"는 보수적 하한을 준다.

```
        p̂ + z²/2n − z·√( p̂(1−p̂)/n + z²/4n² )
하한 = ─────────────────────────────────────────     (p̂=s/n, z=1.96=95%)
                  1 + z²/n
```

| 키워드 | 성공/제품 | 단순 성공률 | Wilson 하한 |
|---|---|---|---|
| 공주 | 1/1 | 1.00 | **0.21** (n=1이라 폭락) |
| 족발 | 3/6 | 0.50 | **0.19** (n=6, base 아래) |
| 하와이 | 10/12 | 0.83 | **0.55** (n 충분, 덜 깎임) |

- **어디 쓰이나**: Reddit·Amazon 리뷰 랭킹("리뷰 적은데 100%" 거품 방지), A/B 테스트 전환율, 임상시험 발생률 — **소표본·극단 비율(0%·100% 근처)**에서 표준 도구. 단순 Wald 구간은 그런 경우 음수·폭0이 나와 못 씀.
- **우리 용처**: 키워드 성공률도 공주(1/1)·족발(3/6)처럼 소표본·극단이라 동일 논리로 거품 제거.

## 3. 임계점과 의미

| 지표 | 컷 | 의미 |
|---|---|---|
| raw 직접성공률 | **≥ 0.50** | base의 약 2.1배 · 단 제품의 **과반 성공** · 전체 키워드 상위 8% |
| | 0.40 ~ 0.50 | base의 1.7~2.1배 (과반 미만) |
| | ≤ 0.238 | base 이하 = raw 신호 없음 |
| Wilson 하한 | **≥ 0.238 (base)** | 표본이 작아도 95% 비관적으로 base 초과 = 우연 아님 |
| | < 0.238 | raw가 높아도 소표본이라 base와 구분 불가 (예: 족발 3/6, W=0.19) |
| Δprob | > +0.01 | 인과 유발 확인 (확실) |

## 4. 발표 등급 (3축 합성)

| 등급 | 규칙 | n | 발표 표현 |
|---|---|---|---|
| 강증거 | `raw≥0.5 ∧ Wilson≥base ∧ Δ확실` | 36 | **헤드라인 "성공 키워드"** (실증·통계·인과 3박자) |
| 보통증거 | `Δ확실 ∧ (raw≥0.4 ∨ Wilson≥base) ∧ ¬강증거` | 18 | 처방 가능, **"보장" 표현 자제** |
| 모델신호(raw약함) | `Δ확실 ∧ raw<0.4 ∧ Wilson<base` | 7 | **"모델 포착 잠재신호"**로만 (raw는 base 수준) |
| 보류(Δ노이즈) | `판정=불명확(Δ±0.01)` | 23 | 발표 제외 권장 |
| 조건부(IP) | `판정=조건부` | 5 | **"IP 콜라보 전용"** (단독 처방 금지) |

> **"보장" 금지**: raw 0.5는 "과반 성공 = 평범한 키워드의 2배"이지 성공 보장이 아니다.

## 5. 발표 핵심 문장

> 평범한 키워드는 단 제품의 **4개 중 1개(~24%, base)**만 성공한다. 
> **강증거 killer**는 단 제품의 **과반(≥50%)이 성공** — 전체 키워드 상위 8%에 들면서, 
> 그 성공률이 소표본 우연이 아니고(Wilson≥base), 넣었을 때 실제로 성공확률을 올린다(Δprob>0). 
> = **실증·통계·인과 세 증거가 모두 통과한 키워드.**
