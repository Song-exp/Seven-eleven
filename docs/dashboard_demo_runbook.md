# 대시보드 시연 런북

> 생성 2026-06-24 · 모델 v2_sweepA · 메타패스 = 시너지(combo_grow) 레일

대시보드는 두 모드로 동작한다. **시너지 메타패스(원하는 동작)는 라이브에서 자동으로 나온다.**

---

## 모드 A — 라이브 (권장, 완성형): 시너지 메타패스 + 임의 키워드

1. **서버 실행** (프롬프트에 `!` 붙여 이 세션에서):
   ```
   ! python -m uvicorn src.eval.api:app --port 8000
   ```
   - 첫 요청 시 모델 1회 로드(수십 초), 이후 시드당 ~1-2s.
2. **브라우저에서 접속**: `http://localhost:8000/`
   - api.py가 dashboard.html + config.js를 직접 서빙. (`/` → 대시보드)
3. **시연 흐름**:
   - 검색창에 **아무 키워드**(마라·로제·고창 등) 입력 → 추론 → 속성 칩 선택 → **네트워크 생성**
   - 메타패스 백본 = **시너지 레일**(`/combo` = combo_grow): 후보는 관련성(공기)으로 추리고, **더해서 성공확률이 오르는(headroom Δ) 순서로 이어감**. 대체재/포화면 거기서 끊김.
   - 노드 클릭 → 보완/겹침 라벨 + 근거(키워드 타입·예시상품).
4. **확인 포인트**: `마라` 검색 시 메타패스가 `마라 → 누들 → 짭조름함 → 콜라보 → 라면`(보완 키워드를 타고 감)으로 뜨면 정상. 겹침(탕·동파육)은 백본에서 빠진다.
5. **두 노드 클릭(궁합)**: 노드 2개 연속 클릭 → ① **함께 쓰면? = 두 키워드 직접 쌍 시너지**(Δ, 라이브 `/combo/pair`) 헤드라인 + ② **이어지는 길 = 시너지 가중 최단경로**(각 구간 Δ 표시, 음수면 겹침). 경로는 시너지 좋은 순서로 이어지고, 구간 수치로 어디서 겹치는지 보인다.

> 임의 자연어 트렌드 확장(미등록어)은 Ollama Gemma가 켜져 있어야 함. 없어도 그래프에 있는 키워드(마라·라면 등)는 정상 동작.

---

## 모드 B — 오프라인 (서버 없이, 휴대용 데모)

1. **`Dashboard/dashboard.html` 더블클릭** (file://).
2. 동작 범위:
   - **등록 트렌드 450개**: 검색창에서 추론·네트워크 생성 가능 (예: `약과`).
   - **구운 combo 시드 8개**(마라·로제·흑임자·약과·고창·하와이·두바이·말차): 선택 시 **시너지 메타패스** 표시.
   - 그 외 키워드: 추론 안 되거나 어텐션 fallback(시너지 아님).
3. 한계: 시너지는 모델 필요 → 오프라인은 **구운 시드만** 시너지. 임의 키워드는 라이브 필요.

> 데모 시드를 더 굽고 싶으면:
> ```
> python -m scripts.export_combo_dashboard 마라 로제 고창 <원하는키워드…>
> ```
> (combo_data.js를 덮어쓰므로 원하는 시드를 한 번에 나열)

---

## 캐시 갱신이 필요한 경우

| 무엇을 바꿨나 | 재생성 명령 |
|---|---|
| 확정 키워드(keyword_final.csv) tag·include | `python -m scripts.export_dashboard` (config.js) |
| 오프라인 combo 시너지 시드 | `python -m scripts.export_combo_dashboard <시드…>` (combo_data.js) |
| 키워드 근거(예시상품) | `python scripts/gen_keyword_evidence.py` → `python -m scripts.export_dashboard` |

## 요약

- **완성형 시연 = 모드 A(라이브).** 시너지 메타패스·임의 키워드·근거 전부 동작. `uvicorn` 띄우고 `localhost:8000/` 접속.
- **휴대용 데모 = 모드 B(오프라인).** 서버 없이 등록 트렌드 + 구운 8개 시드. 시너지는 구운 시드만.
- 당신이 본 "어텐션 메타패스(모순)"는 모드 B에서 **안 구운 키워드(마라)** 라 어텐션 fallback된 것. **모드 A이거나, 모드 B라도 구운 시드면 시너지 메타패스가 나온다.**
