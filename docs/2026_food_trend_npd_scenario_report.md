이 보고서는 **① 2026 실제 트렌드·상품 조사 → ② 상품 속성 추출 → ③ 대시보드 키워드 조합 검증 → ④ 네트워크 검색 쿼리 + 최종 기획 시나리오**의 4단계로, 각 단계가 다음 단계의 입력이 되도록 논리적으로 연결되어 있습니다. 모든 대시보드 수치는 라이브 API(`/infer`, `/combo`, `/combo/pair`) **실측 호출 결과**입니다.

## ⭐ 한 줄 결론 (Executive Summary)

> **트렌드 풍미 그 자체(두바이·말차·흑임자·약과·제로·고단백)는 모델상 "매개(mediator)" 또는 "중립(neutral)"일 뿐, 흥행을 *유발*하지 않는다. 흥행은 그 풍미를 `한정`·`커스터드`·`촉촉`·`새콤`·`녹음` 같은 검증된 killer 속성과 묶을 때 발생하며, `마라`·`다이어트`·`화끈함` 같은 "바이럴은 크지만 전환은 낮은 mine 함정"은 1차 소구에서 배제해야 한다.**

데이터가 지목한 **최우선 런칭 후보 = "프리미엄 한정 말차 × 커스터드 디저트"** (말차 매개 Δ+0.055 × 커스터드 killer Δ+0.081 × 한정 killer Δ+0.107, 세 페어 모두 synergy>0 보완 검증).

# Step 3 — 데이터 대시보드 기반 키워드 조합 검증

대시보드는 **단순 텍스트 매칭이 아니라** 학습된 HIN-GNN의 *인과 개입(Δprob)*으로 키워드를 평가한다. 검증 경로는 3단 API:

| 단계 | API | 의미 (AI 요약 인사이트) |
|---|---|---|
| ① 출발점 탐색 | `POST /infer {trend}` | 임의 트렌드어 → LLM이 그래프 어휘로 매핑한 **출발 속성 후보** |
| ② 시너지 성장 | `POST /combo {seed}` | 시드에서 **marginal synergy** 기준으로 자라는 rail + 붙일 best 노드(`recommend`, Δprob) |
| ③ 페어 인과 | `POST /combo/pair {a,b}` | `synergy = margin(b\|a) − margin(b\|∅)` → **보완(>0) / 대체·잠식(<0)** 판정 |

## 3-2. ★ 고차원 인사이트 — "하입 ≠ 흥행" (mine 함정 식별)

`/infer`가 뽑아준 속성을 **확정 마스터(`keyword_final.csv`) 태그**와 대조하면, 텍스트 매칭만으로는 안 보이는 **숨은 소비 맥락**이 드러난다:

# Step 4 — 네트워크 검색 시행 전략 및 최종 기획 시나리오

## 4-1. 실제 입력 검색 쿼리 (대시보드/API 그대로 사용 가능)

```bash
BASE="https://graduated-christine-brunswick-creating.trycloudflare.com"

# [Q1] 트렌드어 → 출발 속성 (대시보드 검색창에 "말차" 입력과 동일)
curl -X POST $BASE/infer       -H "Content-Type: application/json" -d '{"trend":"말차"}'

# [Q2] 시드 시너지 서브네트워크 (노드 클릭 → rail/recommend)
curl -X POST $BASE/combo       -H "Content-Type: application/json" -d '{"seed":"말차","max_hops":4}'

# [Q3] 두 속성 궁합 인과 (두 노드 클릭 → 구간 시너지)
curl -X POST $BASE/combo/pair  -H "Content-Type: application/json" -d '{"a":"말차","b":"커스터드"}'
curl -X POST $BASE/combo/pair  -H "Content-Type: application/json" -d '{"a":"한정","b":"말차"}'

# [Q4] 보유 속성 풀에 붙일 best 노드 (조합 확장 추천)
curl -X POST $BASE/combo/recommend -H "Content-Type: application/json" \
     -d '{"seed":"말차","pool":["커스터드","한정","쌉싸름함","촉촉","새콤","녹음"],"top":10}'

# [Q5] 선택 속성 1-hop 종합 네트워크 (최대 3개)
curl -X POST $BASE/network     -H "Content-Type: application/json" \
     -d '{"trend":"말차 한정 디저트","attrs":["말차","커스터드","한정"]}'
```

대시보드 UI 등가 동작: **검색창에 "말차" → 출발 속성 칩 노출(Q1) → 칩 클릭 시 rail 성장 네트워크(Q2) → 두 노드 클릭 시 구간 시너지 %p(Q3)**. (file:// 단독 구동 시 시너지 미표시 — 반드시 라이브 서버 필요)

## 4-2. 데이터가 지목한 3개 런칭 후보 (우선순위순)

### 🥇 후보 A — "프리미엄 한정 말차 커스터드" (최우선)
- **조합 근거**: 말차(매개, 트렌드 +129.8%) × 커스터드(killer Δ+0.081) × 한정(killer Δ+0.107) × 쌉싸름함(recommend Δ+0.110). **3 페어 모두 synergy>0 보완** + rail `말차→쌉싸름함→한정→식감→케이크`.
- **컨셉**: 제주 말차 커스터드 크림빵/케이크, **시즌 한정** 에디션. 쌉싸름한 말차 ↔ 달콤 커스터드 대비.
- **기대**: 단일 killer 두 개를 매개 트렌드에 얹어 흥행 확률 상단(커스터드 단독성공률 0.61, 한정 0.60).

### 🥈 후보 B — "두바이 카다이프 × 커스터드/녹음 텍스처 디저트"
- **조합 근거**: 두바이 rail이 카다이프→소르베→케이크로 자라고, recommend 1·2위가 **녹음 +0.086·커스터드 +0.083(killer)**. 두바이|피스타치오 보완(+0.0006).
- **주의(데이터 반증)**: **두바이×말차 잠식(−0.005)** → 두바이-말차 하이브리드는 비추. 두바이는 **녹음/커스터드/카다이프**로 묶을 것.
- **컨셉**: 카다이프 바삭 + 커스터드 크리미 대비, 녹음(시즌) 한정.

### 🥉 후보 C — "할매니얼 흑임자 × 한정 (단, 커스터드와 분리)"
- **조합 근거**: 흑임자 rail `흑임자→촉촉→묵직함`, recommend 커스터드 +0.049·한정 +0.047·촉촉 +0.038. 고소|쫀득함 보완.
- **주의(데이터 반증)**: **흑임자×커스터드 잠식(−0.050)** → 한 SKU에 동시 투입 금지. 흑임자는 **촉촉·한정·고소·쫀득함**(할매니얼 코어)로 구성, 커스터드는 별도 라인(후보 A)으로.

### ⛔ 데이터 기반 "하지 말 것" (리스크 회피)
- **마라·다이어트·화끈함 단독 소구 금지**: mine 판정(마라 0.174 / 다이어트 Δ−0.079 / 화끈함 Δ−0.047). 기사상 매출↑여도 모델상 흥행 유발 신호 없음 → **신제품 1차 컨셉의 주축으로 쓰지 말 것**(매콤은 흔해서 Δ≈0 노이즈).
- **무지성 트렌드 융합 금지**: 두바이×말차, 흑임자×커스터드처럼 두 핫트렌드를 합치면 잠식.
