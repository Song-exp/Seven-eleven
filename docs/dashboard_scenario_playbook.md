# 대시보드 기획 시나리오 플레이북 (패널 결론형)

> **원칙:** 모든 기획안은 **AI 요약 인사이트 패널**의 문장만으로 결론이 나야 한다.
> 즉 **칩 선택 → 패널에 뜨는 ①메타패스(다음의 키워드 조합) + ②🔑흥행/🧪매개 키워드** 로 제품이 도출돼야 한다. (노드 클릭 pair 시너지는 *보조 검토*이지 기획 근거 아님)
> **서버:** `uvicorn src.eval.api:app` 가동 필수. **검증:** 2026-06-27 라이브 `/combo` 실측.

---

## 공통 UI 조작 방법

| 동작 | 방법 |
|---|---|
| 시드 검색 | 검색창에 키워드 입력 → 속성 칩 추론 |
| 조합 | 속성 칩 **1~3개 선택** → 네트워크 생성 (각 칩 = 메타패스) |
| **기획 결론** | 우측 **📌 AI 요약 인사이트** → 🎯 메타패스 줄 + 🔑흥행/🧪매개 칩 |
| (보조) 궁합 | 노드 두 개 클릭 → pair 시너지 (참고용, 기획 근거 아님) |

> **판정 기준:** 패널에 🔑흥행 키워드 + 메타패스가 떠야 "패널 결론형". 흥행이 안 뜨는 시드/조합은 본 플레이북에서 제외(pair 의존이라).

## 시나리오 1 — 커스터드 디저트 (범용 흥행 신호)

**영감 출처:** CU 뀨뀨커스타드샌드 (좋아요 2,819) · 깨먹는하트생크림빵 (좋아요 2,830)

### 실행 — 칩 `생크림`(+`빵`) 선택
패널:
```
🎯 다음의 키워드 조합: 생크림 · 촉촉 · 새콤 · 쫄깃함 · 케이크   /   빵 · 짭조름함 · 촉촉 · 케이크 · 달콤
🔑 흥행: 커스터드 · 폭신함      🧪 매개: 카스타드 · 로제
```
교차 확인 — `커스터드`가 흥행으로 뜨는 망: 생크림 · 빵 · 베리 · 버터 · 두바이 (**5개 망 공통**).

### 기획 결론 (패널)
> 🔑 **커스터드**가 모든 디저트 경로의 공통 흥행 → **커스터드 필링**을 코어로, 형태만 차별화(생크림 케이크/베리 롤케이크). 폭신·촉촉 케이크 폼.

## 시나리오 2 — 저당 말차 아이스콘

**영감 출처:** CU 주토피아아이스바 (좋아요 3,702)

### 실행 — 칩 `아이스` 선택
패널:
```
🎯 다음의 키워드 조합: 아이스 · 저당 · 말차 · 콘
🧪 매개: 저당 · 말차 · 콘 · 크런키 · 허쉬 · 맥주   (🔑흥행 없음 — 메타패스+매개로 도출)
```

### 기획 결론 (패널)
> 메타패스가 **아이스 · 저당 · 말차 · 콘**으로 바로 떨어짐 → **저당 말차 아이스콘**(건강 포지션). 매개 크런키·허쉬로 초코 코팅 콘 변형 가능.

## 시나리오 3 — 딸기 한정 빵/케이크

**영감 출처:** CU 홍만당 원조딸기모찌 (좋아요 3,211) — 모찌 포화 → 빵/케이크로 전환

### 실행 — 칩 `딸기`(+`생크림`) 선택
패널:
```
🎯 다음의 키워드 조합: 딸기 · 한정 · 촉촉 · 새콤 · 식감   /   생크림 · 촉촉 · 새콤 · 쫄깃함 · 케이크
🔑 흥행: 한정 · 커스터드      🧪 매개: 감자 · 카스타드 · 말차
```

### 기획 결론 (패널)
> 🔑 **한정**(딸기) + 🔑 **커스터드**(생크림) → **딸기 한정 × 커스터드 생크림 케이크** (빵/케이크 폼, 촉촉). 모찌(말랑함) 방향은 피함.

## 시나리오 4 — 우베 → 고구마 보라 디저트

**영감 출처:** 우베(ube) 글로벌 트렌드(필리핀 보라 yam) — 국내 미출시. 검색어가 **그래프에 없으면 가까운 실제 노드로 자동 번역**되는 흐름.

### 실행 — `우베` 검색 → 칩 `고구마` 선택
```
infer(우베) → [타로 · 고구마 · 단맛 · 부드러움 · 촉촉 …]   ← 미존재어가 analog 칩으로 자동 번역
```
칩 `고구마` 패널:
```
🎯 다음의 키워드 조합: 고구마 · 고창 · 한정 · 짭조름함 · 촉촉
🔑 흥행: 고창 · 한정      IP: 포켓몬스터(🩷인스타형)
```

### 기획 결론 (패널)
> 🔑 **고창 · 한정** → **고창 황토 보라고구마 × 한정 × 촉촉 케이크/빵**. 우베의 보라 크리미 비주얼은 analog 칩 `타로`로 차용(타로 크림 토핑). IP 포켓몬스터(인스타형) SNS.

### 도출 제품 — 고창 보라고구마 케이크 🍠💜 (가을·겨울 한정)
- 메인: 보라고구마 앙금 / 라벨: 고창 황토(흥행 고창) / 시즌: 한정(흥행) / 폼: 촉촉 케이크 / 비주얼: 타로크림 토핑(analog 칩) / IP: 포켓몬스터(인스타형)

## 시나리오 5 — 밤 × 피스타치오 (몽블랑 × 두바이)

**영감 출처:** 2026 메가히트 조합 — 밤(몽블랑·마롱 가을 디저트) × 피스타치오(두바이 초콜릿 트렌드). 둘 다 패널에 🔑흥행이 떠 조합 가능.

### 실행 — 칩 `밤` + `피스타치오` 선택
패널:
```
🎯 다음의 키워드 조합: 밤 · 붕어빵 · 촉촉 · 케이크 · 달콤   /   피스타치오 · 한정 · 당충전 · 카다이프 · 녹음
🔑 흥행: 커스터드(밤) · 한정(피스타치오)      🧪 매개: 붕어빵 · 당충전 · 소르베
```

### 기획 결론 (패널)
> 두 메타패스가 **케이크**로 만나고, 흥행 **커스터드 + 한정** → **밤 커스터드 × 피스타치오 한정 케이크/몽블랑**. 초코 전면화는 지양(피스타치오 본연 녹색·고소).
> *참고(노드 클릭): 밤×피스타치오 pair +0.0218 — 둘이 보완. 단 기획 근거는 패널 흥행.*

### 도출 제품 — 밤 피스타치오 몽블랑 케이크 🌰💚 (가을·겨울 한정)
- 듀얼 히어로: 밤 크림 + 피스타치오 / 코어: 커스터드(흥행) / 시즌: 한정(흥행) / 폼: 촉촉 케이크 / 회피: 초코

## 시나리오 6 — 티라미수 × 단팥 (팥 티라미수, 겨울 한정)

**영감 출처:** 2026 메가히트 조합 — 티라미수(양식 디저트 열풍) × 단팥(할매니얼). 둘 다 흥행 `한정`으로 수렴.

### 실행 — 칩 `티라미수` + `단팥` 선택
패널:
```
🎯 다음의 키워드 조합: 티라미수 · 저당 · 한정 · 케이크 · 시즌   /   단팥 · 한정 · 즉석 · 붕어빵 · 촉촉
🔑 흥행: 한정 · 커스터드      🧪 매개: 저당 · 즉석 · 붕어빵 · 편의점
```

### 기획 결론 (패널)
> 두 메타패스가 **`한정`으로 수렴** + 흥행 **커스터드** → **겨울 한정 단팥 티라미수 케이크**(커스터드·마스카포네 크림 + 팥 레이어 + 촉촉 케이크 + 저당 옵션).

### 도출 제품 — 단팥 티라미수 케이크 ☕🫘 (겨울 한정)
- 시즌: 한정(흥행) / 크림: 커스터드(흥행) / 레이어: 단팥(할매니얼) / 구조: 코코아·커피 / 폼: 촉촉 케이크 / 옵션: 저당(매개)

## 시나리오 7 — 창억떡 → 할매니얼 폭신 샌드 (단팥 인절미, 겨울 한정)

**영감 출처:** 창억떡(떡 프랜차이즈). **떡 정면은 포화**(흥행 없음·anti 우유·치즈) → infer가 인절미·단팥(할매니얼)로 번역, **빵/샌드로 차별화**.

### 실행 — `창억떡` 검색 → 칩 `인절미`+`단팥` 선택
```
infer(창억떡) → 찰떡 · 쫄깃함 · 꾸덕함 · 팥 · 쑥 · 인절미 · 전통 …   ← 떡 브랜드 미존재 → 할매니얼 재료로 자동 번역
```
패널:
```
🎯 다음의 키워드 조합: 인절미 · 달콤 · 맘모스 · 샌드 · 고소   /   단팥 · 한정 · 즉석 · 붕어빵 · 촉촉
🔑 흥행: 폭신함 · 한정      🧪 매개: 인절미 · 샌드 · 약과 · 호떡 · 즉석
```

### 기획 결론 (패널)
> 🔑 **폭신함**(인절미) + **한정**(단팥), 메타패스가 **맘모스·샌드**(빵)로 → **겨울 한정 단팥 인절미 폭신 샌드/케이크**. 떡(포화) 정면이 아니라 **폭신 빵/샌드**로 할매니얼 차별화.

### 도출 제품 — 단팥 인절미 폭신 샌드 🫘 (겨울 한정)
- 폼: 폭신한 맘모스빵/샌드(흥행 폭신함) / 시즌: 한정(흥행) / 필링: 단팥앙금 + 인절미 고소 / 회피: 떡 정면(포화)

## 주의사항

- **패널 결론 원칙**: 위 6개는 모두 **칩 선택 → AI 요약 인사이트(메타패스 + 🔑흥행/🧪매개)** 만으로 제품이 도출된다. pair 시너지·anti는 *보조 검토*이지 기획 근거가 아니다.
- **흥행이 안 뜨는 시드/조합은 제외**: 블루베리·솜사탕·약과×초당 등은 패널에 🔑흥행이 안 떠(전부 매개) pair 분석에 의존 → 본 플레이북에서 제외(데모 비권장).
- **검색어가 그래프에 없으면**(우베·두바이류) infer가 가까운 실제 노드(타로·고구마, 피스타치오·카다이프)로 자동 번역 → 칩으로 노출. 기획은 그 번역된 칩의 패널로 진행.
- **시즌 한정·IP**: 흥행 `한정`이 자주 뜨면 시즌 한정 GTM, IP는 패널의 채널 배지(🩷인스타형=바이럴/🟢POS형=매출)로 활용.
- 라벨은 현 서빙 `v2_sweepA` 기준(🔑흥행=killer / 🧪매개). 모델 갱신 시 패널 재확인.
