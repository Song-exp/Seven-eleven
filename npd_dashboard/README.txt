7-ELEVEN NPD 트렌드 속성 네트워크 대시보드 (오프라인 버전)
==========================================================

[사용법]
1. 이 폴더(npd_dashboard)를 통째로 받습니다.
2. dashboard.html 을 더블클릭해서 브라우저로 엽니다.
3. 끝. 별도 설치·서버 실행 필요 없습니다.

[쓰는 법]
- 검색어(트렌드)를 입력하면 관련 속성 후보가 버튼으로 뜹니다.
- 속성을 검색어당 최대 3개까지 고릅니다.
- "+ 검색어 추가"로 검색어를 여러 개 둘 수 있습니다(각각 탭).
- "네트워크 생성"을 누르면 1-hop 네트워크가 그려집니다.
- 노드 클릭   : 경로 추적기 + 우측 브리핑 패널(성공확률/프로모션/인스타/연결 IP 등)
- 노드 더블클릭 : 1-hop 가지 펼치기 / 접기
- ⛶ 전체화면 버튼 : 큰 화면으로 보기 (ESC로 닫기)

[필요 조건]
- 인터넷: 없어도 동작합니다. (글꼴만 인터넷이 있으면 더 예쁘게 보이고, 없으면 기본 글꼴)
- 백엔드 서버: 필요 없습니다. 모든 계산이 브라우저 안에서 이뤄집니다.

[한계]
- 미리 준비된 트렌드(약 450개) 안에서 동작합니다.
- 목록에 없는 완전히 새로운 키워드는 속성 추출이 안 됩니다("추론 결과 없음" 표시).

[폴더 구성]
  dashboard.html         화면(UI)
  config.js              데이터(트렌드->속성, 속성별 네트워크) - 서버 대체
  vendor/                그래프 라이브러리(vis-network) 로컬 사본
  README.txt             이 파일

[데이터 갱신 - 개발자용]
  모델/데이터가 바뀌면 프로젝트 루트에서:
      python -m scripts.export_dashboard
  로 config.js 를 다시 만든 뒤, 이 폴더의 config.js 를 교체하면 됩니다.
