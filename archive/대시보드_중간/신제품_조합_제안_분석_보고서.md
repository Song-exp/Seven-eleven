# 신제품 조합 제안 섹터 분석 보고서
**작성일**: 2026-04-29
**대상**: 7-Eleven NPD Dashboard 파이프라인

---

## 1. 개요 (Overview)
'신제품 조합 제안' 탭은 사용자가 **특정 카테고리**(예: 조리빵, 과자)를 선택하고 **외부 트렌드 키워드**(예: "뇨끼 열풍", "헬시플레저")를 입력하면, 세븐일레븐 내부 데이터로 구성된 **지식 그래프(Knowledge Graph)**를 탐색하여 최적의 신제품 속성 조합을 추천해 주는 핵심 기능입니다. 

이 프로세스는 크게 세 단계로 이루어집니다:
1. **LLM 속성 추론:** 자연어 트렌드에서 그래프 내부의 규격화된 '속성' 매핑
2. **그래프 임시 주입:** 추론된 속성들을 묶어 가상의 '트렌드 노드' 생성
3. **가중치 우선 탐색 (BFS):** 트렌드 노드에서 출발해 해당 카테고리 제품을 거쳐 나오는 연관 속성 탐색

---

## 2. LLM 기반 트렌드 속성 추출 (`llm_connector.py`)
사용자가 입력한 모호한 트렌드 단어를 대시보드 내부 네트워크가 이해할 수 있는 **정형화된 속성 노드**로 변환하는 과정입니다.

- **프롬프트 엔지니어링**:
  그래프에 존재하는 모든 속성 노드 목록(`all_attributes`)을 프롬프트에 주입하여, LLM(Gemma 4)이 반드시 **"목록 내에 존재하는 단어"**로만 매핑하도록 강제합니다.
- **점수 산출**:
  단순히 매핑만 하는 것이 아니라 `{"attribute": "이탈리안", "score": 0.95}` 형태로 연관도 점수(0.0~1.0)를 반환하도록 설계되었습니다.
- **폴백(Fallback) 안전망**:
  만약 원격 데스크탑 서버가 꺼져 있거나 LLM 응답에 실패할 경우, 입력한 트렌드 키워드와 내부 속성 단어 간의 '글자 겹침(부분 일치)' 정도를 수치화하여 대체 반환하는 `_fallback_infer` 로직이 내장되어 있어 시연 중 셧다운을 방지합니다.

---

## 3. 지식 그래프 연결 구조 (`network_builder.py`)
LLM을 통해 추출된 속성들은 미리 구축된 4,700여 개의 노드와 24만 개의 엣지로 구성된 지식 그래프 위에서 동작합니다.

- **노드(Nodes)**:
  `Product`(상품), `Attribute`(속성), `IP`(콜라보/캐릭터), `Event`(행사) 총 4종으로 구성되며, 상품 노드는 `category`(대분류명) 메타데이터를 가집니다.
- **엣지(Edges)**:
  `final_edgelist_with_trend.parquet` 데이터를 기반으로 로드됩니다. 여기에는 '상품-속성', 'IP-속성' 간의 연관도가 `weight`(가중치)라는 값으로 미리 계산되어 들어있습니다.

---

## 4. 가중치 기반 BFS 신제품 조합 탐색 (`graph_engine.py`)
가장 핵심이 되는 추천 엔진으로, `propose_by_trend` 함수에서 작동합니다.

1. **가상의 트렌드 노드 주입**:
   LLM이 추론한 속성 5개(예: 이탈리안, 고소함 등)를 각각의 `score`를 엣지 가중치로 삼아, 가상의 노드(예: `trend_뇨끼 열풍`)와 연결하여 그래프에 임시 주입합니다.
2. **우선순위 큐(Priority Queue) 기반 탐색**:
   가상의 트렌드 노드에서 출발하여 **최대 3-Hop(3단계)** 이내의 주변 노드들을 훑습니다.
   일반적인 BFS가 아닌 **누적 가중치 합산** 방식의 다익스트라(Dijkstra)와 유사한 탐색을 진행하여 연관성이 높은 경로를 먼저 파고듭니다.
3. **카테고리 필터 적용**:
   탐색 도중 `Product`(상품) 노드에 도달했을 때, 사용자가 프론트엔드에서 선택한 카테고리(예: `유음료`)와 일치하지 않으면 해당 경로는 그 즉시 탐색을 중단(`continue`)하고 쳐냅니다.
4. **결과 수집 및 정렬**:
   탐색 중 다른 `Attribute`(속성) 노드에 도달하면, 거쳐온 경로(Path)와 총 누적 가중치(Total Weight)를 수집합니다. 이후 `_deduplicate_and_rank`를 통해 중복된 속성 조합을 제거하고, 가중치가 가장 높은 순서대로 Top K개의 조합을 반환합니다.

---

## 5. 대시보드 렌더링 (`dashboard.html` & `server.py`)
서버에서 탐색이 완료되면 JSON 형태로 프론트엔드에 응답합니다.

- **점수(Score) 배지 처리**:
  누적 가중치(`total_weight`)가 높은 것은 초록색 뱃지(High), 중간은 노란색 뱃지(Mid)로 등급을 매겨 카드 상단에 노출합니다.
- **Path Labels (설득 근거 제공)**:
  왜 이 조합이 추천되었는지(예: `뇨끼 열풍` → `이탈리안` 속성 → `기존 A상품` → `새로운 속성 B` 도달)를 `path_labels` 데이터로 반환받아, "기존 OOO 상품을 벤치마킹한 속성"이라는 기획의 설득 근거로 사용자가 확인할 수 있도록 설계되었습니다.
