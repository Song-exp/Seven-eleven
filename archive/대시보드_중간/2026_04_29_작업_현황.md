## 프로젝트 개요

세븐일레븐 내부 상품 데이터 + 커뮤니티 트렌드 데이터를 결합한 **지식 그래프 기반 NPD 대시보드** 파이프라인.

- **목표:** 트렌드 키워드 입력 → Gemma LLM 속성 추론 → 네트워크 BFS → 신제품 속성 조합 제안
- **배포:** 대시보드(Vercel) + 백엔드(노트북 FastAPI + ngrok)
- **LLM:** `gemma4` via Ollama — **데스크탑**에서 실행, ngrok으로 노트북에 연결

### 🔴 우선순위 높음

#### 1. 노트북 `.env` → remote 모드 전환

데스크탑 담당자로부터 아래 두 가지 정보 수령 후 `.env` 수정:

```ini
LLM_MODE=remote
REMOTE_LLM_URL=https://xxxx.ngrok-free.app   ← 데스크탑 ngrok URL
REMOTE_LLM_KEY=MAPISODE_SECRET_2026           ← 고정값
```

수정 후 서버 재시작 → `http://localhost:8000/api/health` 에서 `"llm_mode": "remote"` 확인

### 🟡 우선순위 중간

#### 2. 사전 캐싱 트렌드 키워드 확정 및 캐시 빌드

팀 내 시연용 트렌드 키워드 확정 후:

```powershell
python trend_cache_builder.py --trends "뇨끼 열풍" "헬시플레저" "무알콜" --top_n 5
```

→ `data/trend_cache.json` 생성 → 서버 재시작 시 자동 로딩

#### 3. E2E 테스트 (실데이터 + remote LLM 연결 후)

```powershell
python e2e_test.py
```

탭 1(신제품 제안) · 탭 3(부진 진단) 전체 흐름 브라우저 수동 확인

#### 4. Vercel config.js ngrok URL 갱신

```powershell
# config.js API_BASE_URL 수정 후
git add config.js; git commit -m "chore: update ngrok URL"; git push
```

## 시연 당일 실행 순서

### 데스크탑 (먼저 실행)

```powershell
# 터미널 1: Gemma API 서버
uvicorn server:app --host 0.0.0.0 --port 8000
# 터미널 2: 외부 노출
ngrok http 8000
# → https://xxxx.ngrok-free.app 주소를 노트북 담당자에게 전달
```

### 노트북 (URL 수령 후)

```powershell
# .env 업데이트 → 서버 재시작
uvicorn server:app --port 8000
# 노트북 외부 노출
ngrok http 8000
# config.js API_BASE_URL 업데이트 → git push → Vercel 재배포 (~1분)
```
