# 중간발표 당일 백엔드 실행 가이드

> **시연 당일, 아래 순서대로 정확하게 실행해야 원격 LLM과 대시보드가 정상적으로 연동됩니다.**

---

## 🖥️ 1. 데스크탑 (원격 LLM 서버 담당)

가장 먼저 데스크탑에서 모델과 서버를 구동하고 외부 접속 URL을 열어야 합니다.

### 단계 1: Ollama 구동 확인
1. 데스크탑 전원을 켜고 터미널(PowerShell)을 엽니다.
2. 하단 시스템 트레이에 Ollama 아이콘이 있는지 확인하거나, 터미널에 `ollama run gemma4`를 입력해 모델이 정상적으로 로드되는지 확인합니다.

### 단계 2: API 서버 실행 (터미널 1)
1. `대시보드_중간` 폴더로 이동합니다.
2. 아래 명령어로 FastAPI 서버를 실행합니다. (이 터미널은 시연 내내 켜두어야 합니다)
```powershell
uvicorn gemma_server:app --host 0.0.0.0 --port 8000
```

### 단계 3: ngrok 외부 노출 (터미널 2)
1. 새로운 터미널 창을 하나 더 엽니다.
2. 아래 명령어로 로컬 8000 포트를 외부망으로 엽니다.
```powershell
ngrok http 8000
```
3. 화면에 출력된 **Forwarding URL (`https://xxxx.ngrok-free.app`)** 을 복사하여 **노트북 담당자에게 전달**합니다.

> ⚠️ **주의:** 데스크탑의 터미널 1, 2는 시연이 끝날 때까지 절대 종료하거나 컴퓨터를 절전모드로 전환하면 안 됩니다. ngrok이 재시작되면 URL이 바뀌므로 노트북 설정부터 다시 해야 합니다.

---

## 💻 2. 노트북 (발표 및 대시보드 백엔드 담당)

데스크탑 담당자로부터 **ngrok URL**을 전달받은 후 진행합니다.

### 단계 1: 데스크탑 연결 설정 (`.env`)
1. `대시보드_중간/.env` 파일을 엽니다.
2. 전달받은 URL을 `REMOTE_LLM_URL`에 붙여넣고 저장합니다.
```ini
LLM_MODE=remote
REMOTE_LLM_URL=https://xxxx.ngrok-free.app    # ← 데스크탑에서 받은 URL
REMOTE_LLM_KEY=MAPISODE_SECRET_2026           # ← 고정값
```

### 단계 2: 대시보드 백엔드 서버 실행 (터미널 1)
1. `대시보드_중간` 폴더에서 터미널을 엽니다.
2. 아래 명령어로 FastAPI 백엔드를 실행합니다. (이 터미널은 시연 내내 켜두어야 합니다)
```powershell
uvicorn server:app --port 8000
```
3. 브라우저에서 `http://localhost:8000/api/health` 에 접속해 `"llm_mode": "remote"` 로 잘 잡히는지 확인합니다.

### 단계 3: 프론트엔드용 ngrok 외부 노출 (터미널 2)
1. 새로운 터미널 창을 하나 더 엽니다.
2. 아래 명령어로 노트북의 8000 포트도 외부망으로 엽니다.
```powershell
ngrok http 8000
```
3. 화면에 출력된 **노트북용 ngrok URL**을 복사합니다.

### 단계 4: 프론트엔드(Vercel) 배포 연동
1. `대시보드_중간/config.js` 파일을 엽니다.
2. 복사한 **노트북용 ngrok URL**을 `API_BASE_URL`에 붙여넣고 저장합니다.
```javascript
// config.js
const CONFIG = {
  API_BASE_URL: 'https://yyyy.ngrok-free.app',  // ← 노트북의 ngrok URL 입력
  API_KEY: 'DEV_KEY',
  // ...
```
3. 변경사항을 GitHub에 푸시하여 Vercel 재배포를 트리거합니다.
```powershell
git add config.js
git commit -m "chore: update ngrok url for demo"
git push
```
4. 약 1분 후 `https://middle-balpyyo-dashboard.vercel.app` 에 접속하여 정상 동작(트렌드 키워드 추론 등)을 확인하면 **시연 준비 끝!**

> ⚠️ **주의:** 다른 팀원들이나 교수님은 Vercel 주소(`https://middle-balpyyo-dashboard.vercel.app`)로만 접속하면 됩니다. 노트북의 백엔드용 터미널 2개도 시연 내내 유지해야 합니다.
